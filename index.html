USU Dining App — Interface Redesign

The brief was to find every UX and UI problem in the university's dining app, then redesign it. We rebuilt how it worked and how it looked, in the same pass.

  • Audited the existing app end to end and catalogued its UX and UI failures — that inventory became the redesign brief.
  • Reworked the experience and the visual design together, rather than restyling flows that were already broken.
  • Added guest access. The original assumed every user had a student account, which left visitors and non-students with no way in.
  • My contribution: cutting the number of clicks needed to move between pages, and producing new logo work for the app.
